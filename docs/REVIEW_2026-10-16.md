# Quality review — 16 October 2026

## Brainstorm and priorities

The product should be dependable before adding more shortcuts. Priorities:

1. Preserve configuration and release held input across interruptions.
2. Explain problems through safe diagnostics and actionable errors.
3. Make pointer setup quick with named presets and the existing live stick display.
4. Keep Arabic prediction and dictation predictable and private.
5. Prove the complete controller-only journey on hardware before declaring a release.

Future design work: guided drift calibration sampled over time, a pointer practice
area, controller focus navigation through every settings field, and microphone/model
setup diagnostics. These are proposals, not implemented features in this revision.

## Changes implemented

- Atomic configuration, profile and AMGP conversion writes; failed replacement
  preserves the original. Added a Windows sharing-violation regression test.
- Numeric validation on configuration load/save, plus `--validate-config`.
  Invalid startup configuration stops startup instead of later overwriting it
  with defaults on exit.
- Status/default helpers no longer change Windows gamepad navigation settings.
- Removed forced termination of other instances by executable name. Duplicate
  launches now respect the existing named mutex, allowing normal input cleanup.
- Controller slot handoff releases previous inputs; disconnection clears the
  recovery chord latch so reconnecting can recover control.
- Profile names cannot contain path separators or alternate-stream syntax.
  UTF-8 BOM profiles load correctly; unique names continue checking past 999.
- Pointer presets: Precision, Balanced and Large display; applied on Save.
- Arabic prediction removes duplicate results, handles a diacritic-only prefix,
  and respects a zero result limit.
- Voice start/stop transitions are serialized; transcription stays busy until
  text delivery finishes. Transcript contents are no longer written to debug logs.
- Added a repeatable verification script with CMake discovery. The test which
  moves the real pointer now requires explicit opt-in.
- Removed unmeasured numerical performance claims from the README.

## Review scope and limits

Inspected configuration/persistence, profile import, engine connection/mode
transitions, pointer math and bindings, keyboard navigation/prediction,
voice lifecycle, settings saving, startup/shutdown, tray and Win32 integration.
Existing automated tests cover additional layout, Arabic shaping, sound, OSD,
hotkey and status behavior. This is a targeted source review and automated debug
pass; it is not proof that every runtime path is defect-free.

## Hardware acceptance still required

- Real controller disconnect/reconnect and handoff between two slots while
  dragging or holding Ctrl/Shift; verify keys and rumble release.
- Back+Start recovery through disabled/fullscreen/keyboard modes.
- Keyboard text focus in Arabic/English and mixed-direction text; monitor
  scaling, caret avoidance and all controller-only settings paths.
- Actual microphone capture, VAD, Whisper model loading and text delivery to
  the intended application, including failure and rapid repeated commands.
- Elevated-window interaction, startup registration, second-instance elevation,
  tray exit and resource measurements.

The XML importer is a hand-written subset parser, not a general XML parser;
its existing sample test depends on a local fixture. Broader fixtures and XML
compatibility need a separate import-focused pass. No release or remote push
was performed by this review.

## Engineering follow-up

Implemented the proposed rest-calibration flow in Settings → Pointer. Its pure
measurement module gives one second to release the sticks, observes radial drift
until four seconds, and proposes the measured peaks plus an 800-unit margin
(minimum dead zone 1500). It requires at least 30 observations and rejects motion
over 12000 units, disconnection and slot changes. Applying the suggestion and
saving remain explicit. Results are discarded when the controller disconnects
or the selected slot changes. The 800/1500/12000 thresholds are initial product
defaults, not hardware-derived universal constants; real-controller evaluation
is still required.

Voice monitors now carry a recording session ID, checked again under the
transition lock before stopping. A monitor from an older recording cannot stop
a newer recording. Missing model files produce an error before microphone
capture. Resampling rejects invalid rates/channel counts and incomplete frames;
tests verify stereo downmixing and output duration. VAD elapsed-time checks use
saturating durations because audio callbacks may update timestamps concurrently.

Configuration validation now rejects malformed nonempty recovery hotkeys.
Atomic saving skips abandoned temporary filenames rather than failing after PID
reuse. The verification script restores PATH on completion.

Automated coverage was expanded for calibration, stale session identity,
resampling boundaries and hotkey validation. UI appearance, controller feel and
real microphone/VAD behavior have not been accepted on hardware in this pass.

Follow-up verification: 123 full-feature tests and 86 headless tests passed
(one interactive pointer test ignored in each suite); strict full-feature
Clippy passed, and the full-feature debug executable was rebuilt successfully.

## Keyboard development

- Added a five-row editing panel in Arabic and English, reachable using the
  existing controller navigation through the bottom-row Edit key. Includes
  copy/paste/cut/select-all, undo/redo, word deletion, forward deletion,
  line boundaries, arrows, Shift, help and return to letters.
- Trailing-word extraction supports lam-alef and Arabic marks while treating
  Arabic punctuation as a boundary. Backspacing a space recovers the previous
  trailing word for suggestions.
- Editing actions and foreground-window changes invalidate stale prediction
  context. Prediction acceptance checks that the word is still offered and
  clears one-shot modifiers before replacing the prefix.
- Paste no longer reads the clipboard into the preview. Target fields edited
  by an external keyboard/mouse within the same window are not fully tracked;
  the preview remains a local typing aid, not a synchronized document editor.
- Tests cover editing tools/layout size, language variants, Arabic context and
  foreground-target changes: 126 full-feature and 86 headless tests passed;
  one interactive test ignored in each. Strict Clippy and debug build passed.
  Visual and controller hardware acceptance remain outstanding.
