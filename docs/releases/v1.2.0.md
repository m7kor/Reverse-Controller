# Reverse Controller v1.2.0 — Keyboard & Reliability

## الجديد

- لوحة تحرير بالعربية والإنجليزية من زر **Edit**: نسخ، لصق، قص، تحديد الكل، تراجع، إعادة، حذف كلمة، Home/End والأسهم. العودة عبر **ABC / حروف**.
- تحسين اقتراحات العربية مع «لا» والتشكيل والترقيم؛ منع سياق الاقتراحات القديم بعد تغيّر النافذة أو عمليات التحرير.
- معايرة انحراف العصا خلال أربع ثوانٍ، مع مراجعة القيم قبل التطبيق والحفظ.
- أنماط حركة جاهزة للدقة والاستخدام المتوازن والشاشات الكبيرة.
- حفظ الإعدادات والملفات الشخصية بطريقة تحافظ على الملف السابق عند فشل الاستبدال.
- إصلاحات استعادة التحكم وتبديل منافذ اليد، والتحقق من الإعدادات واختصارات التشغيل.
- عزل جلسات التسجيل الصوتي، والتحقق من نموذج الصوت قبل التسجيل، وإصلاح حالات بيانات الصوت الناقصة. لا يُكتب نص الإملاء في سجل التشخيص.

## Download and run

Windows 10/11 x64. Download `ReverseController-v1.2.0-windows-x64.zip`, extract
it, and run `ReverseController.exe`. A standalone executable is also attached.
Existing settings remain in `%APPDATA%\ControllerCompanionRust`.

Offline dictation requires a separately obtained multilingual `ggml-base.bin`
or `ggml-tiny.bin` in `%APPDATA%\ControllerCompanionRust\models`.
Voice model files are not bundled with this release.

## Keyboard and calibration

Open the keyboard with L3 and select **Edit** in the bottom row. A selects a key;
X deletes backwards, Y inserts a space, LB/RB move the caret, LT switches symbol
layers, RT applies Shift, Back changes language, and R3 moves the keyboard.
Redo uses Ctrl+Y and Delete word uses Ctrl+Backspace; target apps determine their behavior.

In Settings → Pointer, choose **Measure stick drift**, release both sticks for
four seconds, review the recommendation, select **Use suggested dead zones**,
and Save. Disconnects, slot changes and excessive movement cancel the measurement.

## Validation and limits

- 126 full-feature unit tests passed; 86 headless tests passed.
- One interactive pointer test is excluded from each default run.
- Strict full-feature Clippy passed; the Windows x64 release build is included.
- Controller hardware, microphone capture/VAD, multiple monitors and DPI behavior
  still need manual acceptance testing. The typing preview does not mirror edits
  made by other devices inside the same text field.
- This release is not code-signed. Performance numbers are not benchmark guarantees.
- Verify downloads against the attached `SHA256SUMS.txt`.

Source and build instructions are in the repository README. `Cargo.lock` is
included for repeatable dependency resolution.
