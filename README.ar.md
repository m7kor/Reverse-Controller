## 📥 التثبيت

1. حمّل `ReverseController.exe` (أو الملف المضغوط المحمول) من [صفحة الإصدارات](https://github.com/m7kor/Reverse-Controller/releases/latest).
2. شغّله، وسيعرض عليك التثبيت لمستخدمك بدون صلاحيات مسؤول: يُنسخ إلى `%LOCALAPPDATA%\Programs\Reverse Controller`، ويظهر في قائمة ابدأ، ويمكن إزالته من **الإعدادات ← التطبيقات ← التطبيقات المثبتة**.
3. اختر **لا** لتشغيله كنسخة محمولة بدون تثبيت (ولن يسألك مرة أخرى).
4. في أول تشغيل تفتح الإعدادات على **البداية السريعة**: دليل تعليمي في دقيقة تُعلَّم فيه كل خطوة عند تنفيذها بيد التحكم.

تشغيل نسخة أحدث يحدّث النسخة المثبتة. أوامر سطر الأوامر: `--install` و`--uninstall [--quiet]`.

## 📖 نظرة عامة

**Reverse Controller** إعادة هندسة مفتوحة المصدر بلغة Rust لبرنامج *Controller Companion*. يحوّل تقريباً أي يد ألعاب إلى بديل كامل للماوس والكيبورد، بدون تعريفات إضافية:

| يد التحكم | طريقة الاتصال | ملاحظات |
| :--- | :--- | :--- |
| ‏Xbox Series / One / 360 والأيادي بوضع Xbox | XInput | الاهتزاز ومستوى البطارية |
| PlayStation 5 — DualSense وDualSense Edge | واجهة عصا التحكم في ويندوز | زنادات تناظرية، زر PS = Guide |
| PlayStation 4 — DualShock 4 | واجهة عصا التحكم في ويندوز | زنادات تناظرية، زر PS = Guide |
| Nintendo Switch Pro | واجهة عصا التحكم في ويندوز | الأزرار حسب مكانها (السفلي = A) |
| أيادٍ أخرى USB / بلوتوث | واجهة عصا التحكم في ويندوز | التخطيط القياسي |

الأزرار تُربط حسب مكانها، فكل الاختصارات تعمل بنفس الطريقة على كل يد. عند توصيل أكثر من يد تُستخدم يد Xbox أولاً.

ما يقدمه:

- 🖱️ **المؤشر والتمرير** مع مناطق خمول وتسارع ومنحنى اندفاع عند التثبيت، ووضع القناص بزناد LT، ودقة AltSnap اختيارية، و**مؤشر ذكي** يبطئ فوق الروابط والأزرار لتسهيل النقر على الأهداف الصغيرة (والدفع الكامل يمر بسرعة كاملة).
- ⌨️ **كيبورد على الشاشة** بالعربية والإنجليزية: الكتابة بالأسهم أو بالمؤشر، وضع منقسم بعصيين، اقتراحات كلمات تتعلم كلماتك، ولوحة تحرير.
- 🪟 **التحكم بالنوافذ وسطح المكتب**: المحاذاة والتكبير والتصغير والإغلاق، مساعد مبدل المهام، أسطح المكتب الافتراضية، سحب النوافذ بالعصا اليمنى، وقائمة دائرية سريعة.
- 📚 **مكتبة أكثر من 80 اختصاراً** تضعها على أي زر: تبويبات المتصفح، نسخ/لصق/حفظ/بحث، لقطة الشاشة، لوحة الإيموجي، سجل الحافظة، تشغيل، بحث ويندوز، مستكشف الملفات، قفل الجهاز، مدير المهام، المكبر، نقل المؤشر للشاشة التالية وغيرها.
- 🎮 **الألعاب تحتفظ بيد التحكم**: يتوقف التحكم المكتبي تلقائياً في الألعاب بملء الشاشة (المتصفحات ومشغلات الفيديو تبقى قابلة للتحكم) ولا يلمس اهتزاز اللعبة أبداً.
- 🌐 **برنامج ثنائي اللغة**: نافذة الإعدادات كاملة بالعربية (من اليمين لليسار) والإنجليزية، ويمكن التبديل في أي وقت.

## 🎮 دليل الأزرار

### 1. وضع سطح المكتب (الأزرار الافتراضية)

| الزر | الوظيفة |
| :--- | :--- |
| **العصا اليسرى** | تحريك المؤشر |
| **العصا اليمنى** | التمرير (عمودي وأفقي) |
| **A** | نقر أيسر (اضغط مطولاً للسحب) |
| **X** | نقر أيمن |
| **B** | مسح للخلف (Backspace) |
| **Y** | تشغيل / إيقاف الوسائط |
| **الأسهم (D-Pad)** | مفاتيح الأسهم (تتكرر مع الضغط المطول) |
| **LB / RB** | المقطع السابق / التالي |
| **LT** | ‏Ctrl — والضغط عليه يبطئ المؤشر أيضاً (وضع القناص) |
| **RT** | ‏Shift — مثلاً RT + الأسهم لتحديد النص |
| **L3** | فتح / إغلاق الكيبورد |
| **R3** | نقر أوسط |
| **Start** | إدخال (Enter) |
| **Back** | اضغط مطولاً للوظائف الإضافية (بالأسفل) |
| **Guide** | قائمة ابدأ · اضغط مطولاً 2.5 ث لإطفاء اليد اللاسلكية |

يمكن تغيير كل زر من صفحة **الأزرار** في الإعدادات.

### 2. الوظائف الإضافية (مع الضغط على Back)

| الاختصار | الوظيفة |
| :--- | :--- |
| **Back + Start** | تشغيل/إيقاف التحكم المكتبي (يعمل دائماً حتى وهو متوقف) |
| **Back + B** | إلغاء (Esc) |
| **Back + X** | تصغير كل النوافذ (Win+M) |
| **Back + سهم ← / →** | محاذاة النافذة يساراً / يميناً |
| **Back + سهم ↑ / ↓** | رفع / خفض الصوت (مع مؤشر على الشاشة) |
| **Back + LB** | كتم الصوت |
| **Back + RB** أو **Back + RT** | مبدل النوافذ (Ctrl+Alt+Tab) |
| **Back + LT** | المقطع السابق |
| **Back + L3** | قفل السحب (تثبيت النقر الأيسر) |
| **Back + R3** | القائمة الدائرية السريعة |
| **Back + العصا اليمنى** | تحريك النافذة التي تحت المؤشر |
| **Back + A / Back + Y** | الشاشة الخارجية فقط / شاشة الكمبيوتر فقط |
| **Back + Guide** | إطفاء يد التحكم |

أضف اختصاراً إضافياً لأي زر غير مستخدم من صفحة الأزرار.

### 3. مساعد مبدل المهام

أثناء فتح Alt+Tab أو عرض المهام: **الأسهم / العصا اليسرى / LB / RB** للتنقل، **A** للفتح، **B** للإلغاء، **X** لإغلاق النافذة المحددة.

### 4. القائمة الدائرية (Back + R3)

وجّه بالعصا اليسرى واضغط **A** (أو انقر): الكيبورد · رفع الصوت · عرض المهام · خفض الصوت · سطح المكتب · لصق · إغلاق البرنامج · لقطة شاشة. المركز للإلغاء.

## ⌨️ الكيبورد على الشاشة

يُفتح بزر **L3** أو من أيقونة شريط المهام أو تلقائياً عند النقر على حقل نصي بزر **A**. يظهر على الشاشة التي تعمل عليها، بالحجم والمكان الذي اخترته، ويتذكر المكان الذي نقلته إليه.

| الزر | أثناء فتح الكيبورد |
| :--- | :--- |
| **الأسهم** | التنقل بين الأزرار (**A** يضغط الزر المحدد) |
| **العصا اليسرى + A** | التأشير على أي زر والنقر عليه |
| **أعلى من الصف الأول** | الإجراءات السريعة واقتراحات الكلمات |
| **X / Y** | مسح / مسافة (تتكرر مع الضغط المطول) |
| **RT + X / RT + Y** | حذف كلمة / قبول الاقتراح الأول |
| **LB / RB** | تحريك مؤشر الكتابة يساراً / يميناً |
| **LT** | الأرقام والرموز |
| **RT** | ‏Shift (اضغط زر Shift مرتين لتثبيت الأحرف الكبيرة) |
| **Start / RT + Start** | إدخال / سطر جديد دون إرسال (Shift+Enter) |
| **Back** | تبديل اللغة (ع ⇄ EN) |
| **R3** | وضع النقل: حرّك الكيبورد بالعصا اليمنى ثم R3 للتثبيت |
| **L3 + R3** | الوضع المنقسم: كل عصا تحرك مؤشرها، و**LT/RT** يكتبان الزر الأيسر/الأيمن |
| **B / L3** | إغلاق |

**مساعدات الكتابة**

- **التخطيط العربي** يطابق كيبورد ويندوز العربي (101) بما فيه التشكيل مع Shift وأزرار لام ألف (لا · لأ · لإ · لآ) مُرسلة كحروف حقيقية.
- **التخطيط الإنجليزي** يتبع تخطيط ويندوز النشط (QWERTZ، AZERTY …).
- **✂ لوحة التحرير**: نسخ، لصق، قص، تحديد الكل، تراجع، إعادة، حذف كلمة، Home/End، الأسهم.
- **شريط الأدوات**: معاينة مباشرة، ثلاثة اقتراحات، نسخ، لصق، سطر جديد.
- **تعلّم الكلمات**: الكلمات التي تكتبها مرتين تصبح اقتراحات. تُحفظ فقط في `learned_words.json` بجانب إعداداتك، ويمكن إيقافها أو حذفها من صفحة الكيبورد.

## ⚙️ الإعدادات

انقر على أيقونة شريط المهام (أو شغّل `controller-companion.exe --settings`). لكل موضوع صفحة، والنافذة تعمل كاملة **بالعربية أو English** — بدّل من الشريط الجانبي أو صفحة «عام».

| الصفحة | أبرز ما فيها |
| :--- | :--- |
| **الرئيسية** | الحالة المباشرة، البروفايل، البطارية، تحذيرات التعارض، ووظيفة كل زر الآن |
| **المؤشر** | إعدادات جاهزة (دقيق / متوازن / شاشات كبيرة / سريع)، السرعة، التسارع، القناص، AltSnap، منحنى العصا، التمرير |
| **البداية السريعة** | دليل تعليمي: التحريك والنقر والتمرير والتصويب والكتابة والقائمة السريعة، وكل خطوة تُعلَّم عند تنفيذها |
| **يد التحكم** | الأيادي المدعومة، مراقبة مباشرة للأزرار والزنادات والعصي، **معالج ربط الأزرار** لأي يد غير Xbox، معايرة الانجراف في 4 ثوانٍ، مناطق الخمول، نقطة ضغط الزناد، الاهتزاز، تنبيه البطارية |
| **الكيبورد** | المكان، الحجم، المكان المحفوظ، تجنب مؤشر الكتابة، الفتح التلقائي، الوضع المنقسم، المؤثرات الصوتية، تعلّم الكلمات |
| **الأزرار** | مكتبة اختصارات لكل زر، وظائف العصي مع تبديل بنقرة لليد اليسرى، إضافة/إزالة الوظائف الإضافية |
| **البروفايلات** | التفعيل، النسخ، الحذف (مع تأكيد)، إنشاء بروفايل مع قواعد البرامج، استيراد ‎.amgp |
| **عام** | اللغة، التشغيل مع ويندوز، التثبيت والإزالة، الإيقاف في ملء الشاشة واستثناءاته، الإشعارات، اختصار لوحة المفاتيح، الدليل التعليمي، التشخيص |

تُحفظ التعديلات بزر **حفظ التغييرات** (أو Ctrl+S)، وعند الإغلاق مع تغييرات غير محفوظة يسألك البرنامج أولاً. يطبّق البرنامج في الخلفية الإعدادات المحفوظة فوراً، بما فيها اختصار التشغيل الجديد.

**أيقونة شريط المهام** يد تحكم يتغير لونها حسب الحالة (نشط، متوقف للعبة، مطفأ، بدون يد)، وتلميحها يعرض الوضع والبروفايل والبطارية.

## 🗂 البروفايلات

البروفايل مجموعة أزرار محفوظة. أضف له أسماء برامج (مثل `vlc.exe, chrome.exe`) فيتولى التحكم عند فتح أحدها، ثم يعيد البروفايل الذي اخترته — التبديل التلقائي لا يُحفظ مكان اختيارك أبداً. البروفايلات في `%APPDATA%\ControllerCompanionRust\profiles`، ويمكن استيراد ملفات AntiMicroX ‏`.amgp` من الإعدادات أو بالأمر `--convert`.

## 🩺 حل المشكلات

شغّل **تقرير التشخيص** من قائمة الأيقونة أو الإعدادات ← عام (أو `controller-companion.exe --doctor`). يفحص ملف الإعدادات وتعارض الأزرار وكل البروفايلات وXInput والأيادي المتصلة وصلاحيات المسؤول والشاشات وحالة الإيقاف في ملء الشاشة، ثم يحفظ `diagnostics.txt` بجانب إعداداتك.

| المشكلة | الحل |
| :--- | :--- |
| لا شيء يتحرك | اضغط **Back + Start**، وراجع تلميح الأيقونة والتقرير |
| متوقف داخل متصفح أو مشغل فيديو | أضف البرنامج في عام ← *استمرار التحكم في برامج ملء الشاشة* |
| المؤشر ينجرف | صفحة يد التحكم ← *قياس الانجراف* ← استخدام القيم المقترحة ← حفظ |
| لا يمكن النقر على نافذة مسؤول | الأيقونة ← *تشغيل كمسؤول* |

## 🛠️ البناء من المصدر

المتطلبات: ويندوز 10/11 بنظام 64 بت و[أدوات Rust ‏(MSVC)](https://rustup.rs/).

</div>

```powershell
git clone https://github.com/m7kor/Reverse-Controller.git
cd Reverse-Controller
cargo build --release                 # target\release\controller-companion.exe
powershell -File scripts\check.ps1    # الاختبارات وClippy الصارم للنسختين
```

<div dir="rtl">

يطلب البرنامج صلاحيات المسؤول عند التشغيل (للتحكم بالنوافذ التي تعمل كمسؤول)؛ استخدم `--no-elevate` لتخطي ذلك. قائمة الأوامر الكاملة في [README.md](README.md#%EF%B8%8F-building-from-source).

الإعدادات: `%APPDATA%\ControllerCompanionRust\config.json` · سجل التصحيح: `debug.log` في نفس المجلد.
