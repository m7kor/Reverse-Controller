## 🎯 نظرة عامة وفلسفة المشروع (About The Project)

مشروع **Reverse Controller** هو إعادة هندسة وبرمجة شاملة ومفتوحة المصدر بالكامل من الصفر بلغة **Rust** الصافية لبرنامج **Controller Companion** الشهير لنظام Windows.

يهدف المشروع إلى توفير تجربة تحكم متكاملة وسلسة بسطح المكتب عبر أي يد تحكم (Xbox, PlayStation DualShock 4 / DualSense, Nintendo Switch Pro, Generic XInput/DirectInput)، مع الاستغناء التام عن منصة Steam أو أي خدمات سحابية احتكارية لويندوز، مع دعم استثنائي متكامل للغة العربية.

### 🌟 أبرز الركائز التقنية:
- ⚡ **أداء فائق واستهلاك موارد شبه معدوم:** استهلاك ذاكرة لا يتجاوز **~25MB** أثناء الخمول (مقارنة بـ 150MB+ للحلول المعتمدة على Electron أو C#)، ومحرك استطلاع بتردد **125Hz** مع زمن استجابة فوري أقل من **1.2ms**.
- 🔒 **خصوصية 100% واستقلالية تامة:** لا يتطلب أي اتصال بالإنترنت، لا يعتمد على Steam، ويعمل بكتابة صوتية محلية بالذكاء الاصطناعي (Whisper Local AI) ومتصفح إيموجي مدمج بالكامل.
- 🎨 **تصميم عصري متناسق مع Windows 11:** واجهات رسومية شفافة مبنية بمكتبة `egui/eframe` تدعم تأثيرات Acrylic و Mica مع أصوات نقرات ميكانيكية تفاعلية.
- 🛡️ **استقرار واعتمادية موثقة:** أكثر من **130 اختبار وحدة واختبارات صامتة** بنسبة نجاح 100% وخلو تام من أي تحذيرات تحليل ساكن (Zero Clippy Warnings).

## 🎮 الدليل الشامل لجميع الأزرار والوظائف (Controller Guide)

### 1️⃣ وضع الماوس لسطح المكتب (Desktop Mouse Mode)

الوضع التلقائي عند تشغيل البرنامج واستخدام اليد لتصفح البرامج والمواقع:

| الزر في اليد (Input) | الوظيفة (Action) | الشرح والتفاصيل |
| :--- | :--- | :--- |
| **🕹️ الأنالوج الأيسر (Left Stick)** | **تحريك الماوس (Mouse Move)** | تحريك ناعم وسريع مع مقاومة للارتجاف (Deadzone) وتسارع فيزيائي سلس. |
| **🕹️ الأنالوج الأيمن (Right Stick)** | **عجلة التمرير (Mouse Scroll)** | تمرير عمودي وأفقي فائق النعومة للمستندات وصفحات الإنترنت. |
| **🟢 زر A** | **النقر الأيسر (Left Click)** | النقر الأساسي، السحب، وفتح الملفات والروابط. |
| **🔵 زر X** | **النقر الأيمن (Right Click)** | فتح القائمة الجانبية (Context Menu) وخيارات الملفات. |
| **🔴 زر B** | **المسح والرجوع (Backspace)** | مسح الحرف السابق أثناء الكتابة أو الرجوع خطوة للخلف. |
| **🟡 زر Y** | **تشغيل / إيقاف الوسائط (Play/Pause)** | التحكم الفوري بتشغيل أو إيقاف الموسيقى والفيديوهات. |
| **🔘 ضغطة R3 (الأنالوج الأيمن)** | **الزر الأوسط (Middle Click)** | إغلاق تبويبات المتصفح بنقرة واحدة، أو التمرير التلقائي. |
| **🔘 ضغطة L3 (الأنالوج الأيسر)** | **إظهار / إخفاء الكيبورد (Toggle OSK)** | فتح لوحة المفاتيح الافتراضية العائمة الشفافة على الشاشة. |
| **🎯 الزناد الأيسر (LT)** | **نمط القناص الدقيق (Sniper Mode)** | إبطاء حركة الماوس بنسبة 70% لتحكم مليمتري دقيق. |
| **⚡ الزناد الأيمن (RT)** | **مفتاح Shift (Shift Modifier)** | يعمل كزر `Shift` لتحديد النصوص أو الملفات المتعددة. |
| **⏮️ الكتف الأيسر (LB)** | **المقطع السابق (Previous Media)** | الانتقال للمقطع أو الأغنية السابقة. |
| **⏭️ الكتف الأيمن (RB)** | **المقطع التالي (Next Media)** | الانتقال للمقطع أو الأغنية التالية. |
| **🎛️ أزرار الأسهم (D-Pad)** | **مفاتيح الأسهم (Arrow Keys)** | التنقل بالأسهم في جميع الاتجاهات مع خاصية التكرار السريع. |
| **▶️ زر Start** | **زر الإدخال (Enter)** | فتح البرامج، إرسال الرسائل، أو سطر جديد. |
| **📋 زر Back** | **مفتاح الطبقة المتقدمة (Modifier)** | عند تعليق الضغط عليه، يفعل الاختصارات الثانوية للنظام. |
| **🌐 زر Xbox Guide** | **قائمة ابدأ / إطفاء اليد** | نقرة تفتح قائمة ابدأ، وتعليق الضغط 2.5 ثانية يطفئ اليد اللاسلكية فوراً لحفظ البطارية. |

### 2️⃣ أزرار الكيبورد الافتراضي الشفاف (Virtual Keyboard Mode)

عند الضغط على **L3** يظهر الكيبورد، وتتحول اليد فوراً إلى وضع الكتابة الاحترافي المخصص:

| الزر في اليد (Input) | الوظيفة المخصصة (Custom Keyboard Action) |
| :--- | :--- |
| **🕹️ الأنالوج الأيسر أو D-Pad** | **تحريك المؤشر بين الحروف** في جميع الاتجاهات بسلاسة وسرعة استجابة. |
| **🟢 زر A** | **طباعة الحرف أو الرمز المحدد (Type Key)** مع صوت نقرة ميكانيكية تفاعلية. |
| **🔵 زر X** | **مسح الحرف السابق (Backspace)** مع استمرار المسح السريع عند التعليق. |
| **🟡 زر Y** | **مسافة (Space Bar)** مع استمرار التباعد عند التعليق. |
| **🔴 زر B** | **إغلاق الكيبورد فوراً** والرجوع لسطح المكتب. |
| **⏮️ الكتف الأيسر L1 (LB)** | **تحريك مؤشر الكتابة لليسار مثل السهم (Caret Left)** مع تكرار مستمر لتصحيح النصوص. |
| **⏭️ الكتف الأيمن R1 (RB)** | **تحريك مؤشر الكتابة لليمين مثل السهم (Caret Right)** مع تكرار مستمر. |
| **🎯 الزناد الأيسر L2 (LT)** | **الانتقال لقائمة الأرقام والرموز والأشكال (?123 / #+=)**. |
| **⚡ الزناد الأيمن R2 (RT)** | **تكبير الحروف والتشكيل (Capitalize / Shift / الحركات والهمزات العربية)**. |
| **🔘 ضغطة R3 (الأنالوج الأيمن)** | **تفعيل وضع تحريك الكيبورد (Reposition Mode):** اضغط R3، ثم حرّك الكيبورد بالقير الأيمن في أي مكان، واضغط R3 مجدداً للتثبيت! |
| **🔘 ضغطة L3 (الأنالوج الأيسر)** | **إخفاء الكيبورد فوراً**. |
| **🎮 L3 + R3 معاً** | **تبديل نمط الشطرين (Dual-Stick Split Mode):** تقسيم الكيبورد لنصفين للكتابة باليدين معاً مثل الـ Steam Deck! |
| **📋 زر Back** | **تبديل اللغة فوراً بين العربي والإنجليزي (عربي ⇋ English)**. |
| **▶️ زر Start** | **سطر جديد (Enter)**. |
| **🛠️ زر Edit في الكيبورد** | **فتح لوحة أدوات التحرير المدمجة:** نسخ، لصق، قص، تراجع، إعادة، مسح كلمة، وتحديد الكل. |
| **😀 زر الإيموجي في الكيبورد** | **فتح متصفح الرموز التعبيرية المدمج** المستقل بالكامل والمصنف حسب الفئات. |

### 3️⃣ طبقة الاختصارات المتقدمة (Back Modifier Layer: اضغط مع زر Back)

عند تعليق الضغط على **زر Back**، تتحول باقي الأزرار إلى مركز تحكم بالنظام:

| الاختصار (Button Combo) | الوظيفة (Action) | الشرح والتفاصيل |
| :--- | :--- | :--- |
| **Back + Start** | **تشغيل / إيقاف تحكم اليد (Toggle Controller)** | يعمل على مستوى العتاد دائماً حتى لو كان البرنامج معطلاً لاستعادة الماوس فوراً. |
| **Back + LB (الكتف الأيسر)** | **الكتابة الصوتية بالذكاء الاصطناعي (AI Voice)** | تسجيل صوتك وتحويله لنص عربي أو إنجليزي محلياً بدون إنترنت عبر Whisper. |
| **Back + R3 (ضغطة الأنالوج)** | **القائمة الدائرية السريعة (Radial Pie Menu)** | يفتح قائمة دائرية سريعة بـ 8 اتجاهات للتنقل السريع لأهم البرامج. |
| **Back + L3 (ضغطة الأنالوج)** | **قفل السحب والإفلات (Drag Lock)** | تعليق زر الماوس الأيسر تلقائياً لسحب النوافذ والملفات دون الاستمرار بالضغط. |
| **Back + D-Pad ⬆️ / ⬇️** | **رفع / خفض مستوى الصوت (Volume Control)** | زيادة أو خفض صوت النظام مع مؤشر OSD مرئي وصوت تفاعلي. |
| **Back + D-Pad ⬅️ / ➡️** | **محاذاة النوافذ لليسار / اليمين (Snap Left / Right)** | محاذاة وتثبيت النافذة النشطة لنصف الشاشة (Win+Left/Right). |
| **Back + 🔴 B** | **زر الهروب (Escape)** | إغلاق القوائم المفتوحة أو الخروج من وضع ملء الشاشة. |
| **Back + 🔵 X** | **إظهار سطح المكتب (Show Desktop)** | تصغير جميع النوافذ فوراً والرجوع لسطح المكتب (Win+D). |
| **Back + RB (الكتف الأيمن)** | **مبدل المهام (Task Switcher / Alt+Tab)** | تفعيل مبدل النوافذ مع تنقل سلس بالأسهم واهتزاز تفاعلي. |

### 4️⃣ منظومة الصوت الذكية والماكرو التلقائي (AI Voice Macros)

أثناء التسجيل الصوتي بالذكاء الاصطناعي (عبر **Back + LB** أو زر الميكروفون):
- **إرسال الرسالة تلقائياً:** قل **"أرسل"** أو **"إرسال"** أو **"انتر"** في نهاية كلامك ليتم كتابة النص وضغط زر Enter تلقائياً لإرسال الرسالة!
- **النزول لسطر جديد:** قل **"سطر جديد"** ليتم إدراج سطر جديد تلقائياً.
- **إدراج علامات الترقيم والأشكال:**
  - "فاصلة" ⇦ `،`
  - "فاصلة منقوطة" ⇦ `؛`
  - "نقطة" ⇦ `.`
  - "نقطتان" أو "نقطتين" ⇦ `:`
  - "علامة استفهام" ⇦ `؟`
  - "علامة تعجب" ⇦ `!`
  - "بين قوسين" ⇦ `()`
  - "شرطة" ⇦ `-`
  - "خط مائل" ⇦ `/`
- **قاموس المصطلحات المخصصة (Vocabulary Bias):** يمكنك من واجهة الإعدادات (صفحة Voice & AI) كتابة كلماتك الخاصة أو أسماء الألعاب وحسابات الجيمرز (مثل: "فيفا"، "فورتنايت"، "ديسكورد") ليتم حقنها في تلقين Whisper ليتعرف عليها بدقة 100%.

## 🚀 التشغيل السريع (Quick Start)

التطبيق محمول (Portable) بالكامل ولا يتطلب أي تثبيت:
1. حمّل أحدث ملف مضغوط من صفحة الإصدارات: **[Releases](https://github.com/m7kor/Reverse-Controller/releases/latest)**.
2. فك الضغط في أي مجلد وشغّل `ReverseController.exe`.
3. وصّل يد التحكم واستمتع بالتحكم الكامل بسطح المكتب!
4. تجد أيقونة البرنامج في شريط المهام بجانب الساعة (System Tray):
   - **نقرة يسار:** تفتح لوحة الإعدادات الشاملة (حساسية الماوس، الكيبورد، الصوت، والبروفايلات).
   - **نقرة يمين:** تفتح القائمة السريعة للتشغيل أو الإيقاف أو الخروج.

## 🛠️ البناء من المصدر (Building From Source)

### المتطلبات الأساسية:
- نظام Windows 10 أو Windows 11 (x64)
- بيئة [Rust Toolchain (MSVC Stable)](https://rustup.rs/)
- حزمة Visual Studio C++ Build Tools مع CMake و LLVM/libclang لبناء ميزة الصوت.

```powershell
# استنساخ المستودع الرئيسي
git clone https://github.com/m7kor/Reverse-Controller.git
cd Reverse-Controller

# بناء النسخة المحسنة النهائية (Release Build مع LTO)
cargo build --release --features "gui,voice"

# تشغيل الفحص الكامل واختبارات الوحدة (131 اختبار)
cargo test --features "gui,voice"

# فحص التحليل الساكن الصارم (Zero Warnings)
cargo clippy --all-targets --features "gui,voice" -- -D warnings
```

الملف التنفيذي النهائي سيكون متاحاً في:
`target/release/ReverseController.exe`

## ⚙️ ملفات الإعدادات والبروفايلات (Configuration)

تُحفظ جميع إعدادات البرنامج وحساسية الماوس ومناطق الخمول (Dead Zones) والقاموس الصوتي في المسار:
`%APPDATA%\ControllerCompanionRust\config.json`
